Phishing Email Analyzer

A beginner-friendly cybersecurity project that analyzes emails for common phishing indicators and provides a simple risk assessment.

Features

- Checks for suspicious phishing-related words and phrases
- Detects HTTP links
- Identifies emails containing links
- Performs a basic sender email validation
- Calculates a risk score from 0–100
- Classifies the email as:
  - Low Risk
  - Medium Risk
  - High Risk
- Displays detected phishing indicators

Technologies Used

- HTML
- CSS
- JavaScript

How It Works

1. Enter the sender's email address.
2. Enter the email subject.
3. Paste the email content.
4. Click Analyze Email.
5. The analyzer checks the email for common phishing indicators.
6. A risk score and list of findings are displayed.

Purpose

This project was created as part of my cybersecurity learning journey to practice web development and understand common phishing indicators.

Disclaimer

This tool is intended for educational purposes only. It performs basic rule-based analysis and should not be considered a complete or professional email security solution.
