Fraud Transaction Detector

A frontend-based cybersecurity project that analyzes transaction details and identifies potential fraud indicators using a rule-based risk scoring system.

Project Overview

The Fraud Transaction Detector is designed as a simple investigation-support tool for identifying suspicious transaction patterns.

The application analyzes factors such as:

- Transaction amount
- Location changes
- Unusual transaction times
- New device usage
- International transactions

Based on these indicators, the system calculates a risk score from 0 to 100 and classifies the transaction as:

- Low Risk
- Medium Risk
- High Risk

Technologies Used

- HTML
- CSS
- JavaScript

How It Works

1. Enter the transaction details.
2. Click Analyze Transaction.
3. The JavaScript-based detection system checks the transaction for suspicious indicators.
4. A risk score is calculated.
5. The application displays the risk level and the reasons that contributed to the score.

Risk Detection

The system uses a rule-based scoring approach.

Examples of indicators include:

- High-value transactions
- Different transaction locations
- Transactions during unusual hours
- Use of a new device
- International transactions

The maximum risk score is 100.
