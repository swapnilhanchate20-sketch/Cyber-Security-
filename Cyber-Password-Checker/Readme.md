# Secure Password Checker

## What it does
Checks a password against basic security requirements.

## How it works
1. User enters a password.
2. JavaScript checks its length.
3. It checks for uppercase letters.
4. It checks for lowercase letters.
5. It checks for numbers.
6. It checks for special characters.
7. A score determines Weak, Medium, or Strong.
