# Cyber Fraud Investigation - Secure Authentication Prototype

## About the Project

This project is a beginner-friendly web prototype for a cyber-fraud investigation system.

The project demonstrates how authentication, multi-factor authentication (MFA), authorization, and access control can be connected into one workflow.

## Authentication Flow

The system follows this flow:

Login
↓
MFA Verification
↓
Authorization / Role Selection
↓
Investigation Dashboard
↓
Investigation Notes

## Features

- Username and password login
- Password show/hide option
- MFA verification using a demo OTP
- Role selection
- Access control concept
- Cyber-fraud investigation dashboard
- Investigation case information
- Investigation notes section

## Technologies Used

- HTML
- CSS
- JavaScript
